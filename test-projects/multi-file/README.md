# 多文件模块手动测试项目

每个子目录是一个独立的 Java 项目,可直接拖拽整个文件夹到多文件模式的「导入」区域上传。

| 项目 | 文件数 | 测试重点 |
|---|---|---|
| `bubble-sort/` | 2 | 跨文件高亮跳转、双层循环、数组、三色高亮、交换 |
| `bank/` | 2 | 对象字段、条件分支、构造器、getter 跨文件跳转 |
| `linked-list/` | 3 | 堆对象、引用、跨三文件跳转、数据结构可视化 |
| `fibonacci/` | 2 | 递归、栈帧展开、递归基线条件 |
| `shopping-checkout/` | 6 | 购物结算：商品/购物车/订单/会员折扣/库存校验/积分 |
| `library-loan/` | 6 | 图书馆借阅：图书/会员额度/借还逻辑/逾期罚款 |

上传提示:

- 入口类由后端自动检测(第一个含 `public static void main` 的类),无需手动指定。
- 文件名必须与 `public class` 名一致(Java 规范),每个文件只有一个 public class。
- 建议直接拖拽整个项目文件夹(如 `bubble-sort/`)到导入区,或点「选择文件夹」。

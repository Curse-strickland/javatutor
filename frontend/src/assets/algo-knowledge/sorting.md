# 排序算法速览

排序是算法学习的基础。下面按**稳定 / 原地 / 平均复杂度**对比七种经典排序，帮助你在写代码或分析复杂度时快速选型。

## 冒泡排序

相邻元素两两比较，较大者后移；每轮把当前最大值「冒泡」到末尾。

- **时间**：最好 O(n)，平均/最坏 O(n²)
- **空间**：O(1)，**稳定**
- **适用**：数据量极小或教学演示；实际工程很少用

```java
for (int i = 0; i < n - 1; i++)
  for (int j = 0; j < n - 1 - i; j++)
    if (a[j] > a[j + 1]) swap(a, j, j + 1);
```

## 选择排序

每轮在未排序区间选最小元素，放到已排序区间末尾。

- **时间**：O(n²)（与输入无关）
- **空间**：O(1)，**不稳定**（交换可能跨越相等元素）
- **特点**：交换次数少，但比较次数固定

## 插入排序

维护已排序前缀，逐个把新元素插入正确位置；对**近乎有序**数据表现很好。

- **时间**：最好 O(n)，平均/最坏 O(n²)
- **空间**：O(1)，**稳定**
- **适用**：小规模、在线数据、作为快排/归并的小数组 cutoff

## 希尔排序

按递减增量分组做插入排序，最后增量为 1。是插入排序的「分治预排序」。

- **时间**：取决于增量序列，常见 O(n^1.3) ~ O(n²)
- **空间**：O(1)，**不稳定**
- **直觉**：先让元素大致就位，再精细插入

## 归并排序

分治：拆成两半分别排序，再**合并**两个有序段。

- **时间**：O(n log n)，**稳定**
- **空间**：O(n) 辅助数组（可优化为原地变体，但实现复杂）
- **适用**：链表排序、外部排序、需要稳定性的场景

## 快速排序

选基准 pivot，分区使左侧 ≤ pivot ≤ 右侧，递归左右子区间。

- **时间**：平均 O(n log n)，最坏 O(n²)（可随机化/三数取中缓解）
- **空间**：O(log n) 递归栈，**不稳定**
- **适用**：通用内排序首选；注意 equal 元素多时可用三路划分

## 堆排序

建最大堆后反复取堆顶放到末尾并下沉调整。

- **时间**：O(n log n)，**不稳定**
- **空间**：O(1) 原地
- **适用**：需要 O(1) 额外空间且保证 O(n log n) 最坏复杂度

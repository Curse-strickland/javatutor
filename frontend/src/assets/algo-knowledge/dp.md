# 动态规划 DP

动态规划把原问题拆成**重叠子问题**，用表格或滚动数组存子问题最优解，避免指数级重复计算。

## 核心思想

1. **最优子结构**：全局最优由子问题最优组合得到
2. **重叠子问题**：同一子问题被多次用到 → 适合记忆化或递推填表
3. **无后效性**：当前状态已包含未来决策所需的全部信息

与分治的区别：分治子问题通常**不重叠**（如归并排序）；DP 子问题**大量重叠**（如斐波那契、背包）。

## 常见套路

| 类型 | 状态示例 | 转移直觉 |
|------|----------|----------|
| 线性 DP | `dp[i]` 前 i 个元素最优 | 从 `i-1`、`i-2` 等转移 |
| 背包 | `dp[i][w]` 前 i 件容量 w | 选或不选第 i 件 |
| 区间 DP | `dp[l][r]` 区间 [l,r] | 枚举分割点 k |
| 树形 DP | 节点 u 的子树信息 | DFS 后自底向上合并 |

## 实现要点

- 明确**状态定义**与**初始化**（边界往往决定 80% 正确性）
- 确定**遍历顺序**，保证转移时依赖项已计算
- 空间优化：若只依赖上一行/上一状态，可滚动数组降维

```java
// 0-1 背包一维优化（容量从大到小）
for (Item it : items)
  for (int w = W; w >= it.w; w--)
    dp[w] = Math.max(dp[w], dp[w - it.w] + it.v);
```

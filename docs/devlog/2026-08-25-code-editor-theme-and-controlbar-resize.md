# 2026-08-25 代码区蓝黑配色 + 运行栏左右拖拽调宽

> 涉及仓库：`JavaTutor`（分支 `feat/frontend-code-color-and-controlbar-resize`）
> 状态：已完成并本地验证

## 背景

1. 编辑器 Monaco 语法高亮沿用 Cursor 浅色主题的彩色配色（紫字符串 / 红关键字 / 绿注解），与项目浅色冷灰 + 蓝青 accent 的 Rhodes 档案风不统一。
2. 运行栏（底部控制栏）此前只能拖动位置，无法调整宽度。

## 改动内容

### 1. 代码区蓝黑配色（`Editor.vue`）

将 `cursor-light` 主题的 token 颜色从彩色改为蓝黑系，贴合 `--accent`(#0d9ec4) 与 `--fg`(#12161d)：

| 元素 | 原色 | 现色 |
|---|---|---|
| 关键字 / 修饰符 | A30034 | 0A6D8C |
| 字符串 | 7565CC | 0D7F9E |
| 数字 | 92156A | 0B6E9C |
| 类型 | 005293 | 0A5C80 |
| 注解 | 007041 | 4D5665 |
| 注释 | 14141499 | 8B93A1 |
| 标识符 / 默认 | 141414 | 12161D |

同时把编辑器前景色改 `#12161D`，当前行号与光标改 accent 蓝青 `#0D9EC4`。

### 2. 运行栏左右拖拽调宽（`ControlBar.vue` + `SingleFileShell.vue`）

- 运行栏右边缘新增 `resize-handle`（3px 半透明蓝色竖条，`ew-resize` 光标）。
- 拖拽调整宽度，最小宽度为原始内容宽（只能拖大不能拖小），上限不超出窗口。
- 单文件（`SingleFileShell`）与多文件（`ControlBar`）两套运行栏同步修改。
